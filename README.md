## Requirements

- Python 3.10 or newer: `pip install -r requirements.txt`
- Node.js 18 or newer (solc-js 0.8.24 is installed by `npm install` in `sc/`)
- A LaTeX distribution with `pgfplots` and `pdftoppm` (Poppler) to rebuild the figures

The experiments run on CPU. The reported timings were measured on a Linux virtual machine with two x86-64 vCPUs and 8 GB RAM.

## Datasets

The TON_IoT and Wazihub files are not redistributed. Download them as described in `data/README.md` and place them in `data/`,.
